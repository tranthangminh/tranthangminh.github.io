================================================================
          BOOK FORGE BY MAX v1.0 (Beta) - PORTABLE
================================================================

1. YÊU CẦU HỆ THỐNG / PREREQUISITES:
   - Hệ điều hành: Windows 10 hoặc Windows 11 (64-bit).
   - Đã cài đặt Node.js (tải miễn phí từ https://nodejs.org/ bản LTS).
   - Có sẵn Microsoft Edge (mặc định Windows đã có sẵn).

2. HƯỚNG DẪN CÀI ĐẶT LẦN ĐẦU / FIRST-TIME SETUP:
   - Bước 1: Cài đặt Node.js nếu máy bạn chưa có.
   - Bước 2: Bấm đúp vào file "setup.bat" (chỉ cần chạy 1 lần duy nhất).
             File này sẽ tự động tải các thư viện xử lý sách cần thiết.
   - Bước 3: Mở "Book Forge by Max.exe" và bắt đầu sử dụng!

3. TÍNH NĂNG CHÍNH / KEY FEATURES:
   - PDF to Markdown:
     + Tách chương sách thông minh theo tiêu đề H1/H2/H3.
     + Trích xuất hình ảnh minh họa độ phân giải cao.
     + Tạo bộ khung dự án dịch sách (Translation Bible).
   - Markdown to PDF:
     + Xuất bản sách in chuẩn quốc tế (A5, B5, A4, Pocket, Kindle, US-Trade...).
     + Căn lề gáy so le chuẩn in ấn (Gutter margins).
     + Mục lục in (Table of Contents) tùy chọn 3 cấp độ: H1, H1 & H2, H1, H2 & H3.
     + Cây bookmark phân cấp PDF (Document Outlines).
     + Running headers động theo từng chương.
   - QA Audit:
     + Tự động kiểm tra cú pháp Markdown, thẻ đóng mở và độ tương đương trước khi in.

4. LƯU Ý / IMPORTANT:
   - Giữ nguyên cấu trúc các thư mục "script/" và "Templates/" cùng cấp với file "Book Forge by Max.exe".
