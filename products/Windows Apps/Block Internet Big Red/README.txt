=====================================================
      HOW TO USE - BLOCK INTERNET BIG RED TOOLKIT
=====================================================

STEP 1: BLOCK INTERNET & CLEAR CACHE
- Double-click: "1. Big-Red_Block_Internet.bat"
- Type [1] and press Enter (Ultimate Block mode).
- Wait for the script to automatically clear cached licenses
  and block all apps via Windows Firewall & Hosts file.

STEP 2: ACTIVATE (PATCH)
- Open: "2. GenP-v4.2.1.exe"
- Click the "Search" button (magnifying glass icon) to detect installed apps.
- Click the "Patch" button (pill icon) to apply the fix.
- Done: Open your application and enjoy using it without any popups!

-----------------------------------------------------
* ADDITIONAL NOTES:
- Update GenP: You can open the shortcut
  "GenP Releases - TheMythologist" to check and download
  the latest GenP version whenever Adobe releases new updates.
- Restore Network Access: If you ever want to unblock everything,
  simply run "3. Big-Red_UnBlock_Internet.bat" (select option 1).


=====================================================
    HƯỚNG DẪN SỬ DỤNG - BLOCK INTERNET BIG RED
=====================================================

BƯỚC 1: CHẶN MẠNG & DỌN CACHE
- Nhấp đúp vào file: "1. Big-Red_Block_Internet.bat"
- Nhập phím [1] rồi nhấn Enter (Chế độ Chặn triệt để).
- Chờ script tự động dọn cache và chặn Firewall/Hosts.

BƯỚC 2: KÍCH HOẠT BẢN QUYỀN (PATCH)
- Mở file: "2. GenP-v4.2.1.exe"
- Bấm nút "Search" (icon kính lúp) để tìm các app đã cài.
- Bấm nút "Patch" (icon viên thuốc) để kích hoạt.
- Hoàn tất: Mở app sử dụng bình thường không lo bị quét!

-----------------------------------------------------
* LƯU Ý THÊM:
- Cập nhật GenP mới: Bạn có thể mở shortcut

  các phiên bản GenP mới nhất khi có bản cập nhật.
- Mở lại mạng: Nếu muốn khôi phục lại kết nối mạng như
